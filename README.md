## Описание

В проекте выполнена финальная доводка backend-приложения и инфраструктуры для локального запуска через Docker.

Основной фокус работы:

* аудит безопасности приложения;
* проверка серверной валидации входящих данных;
* проверка прав доступа к защищённым маршрутам;
* проверка обработки пользовательских файлов;
* проверка npm-зависимостей;
* исправление ошибок линтинга и сборки;
* подготовка проекта к проверке через GitHub Actions.

## Подготовка к работе

1. Склонировать репозиторий:

   git clone https://github.com/ReshetnikovAV89/bad-server.git

2. Перейти в директорию проекта:

   cd bad-server

3. Запустить Docker:

   docker compose up -d --build

4. Наполнить базу данных.

Инструкция по импорту тестовых данных находится в файле:

```
.dump/README.md
```

После импорта на главной странице должны отображаться товары.

5. Открыть приложение:

   http://localhost/

6. Открыть страницу авторизации:

   http://localhost/login/

7. Открыть админ-панель:

   http://localhost/admin/

## Проверки

Перед отправкой работы были выполнены проверки backend:

```
cd backend
npm run check
```

Проверка включает:

* сборку TypeScript;
* строгий ESLint;
* проверку форматирования Prettier;
* проверку неиспользуемого кода;
* проверку пустых файлов;
* проверку потенциально опасного кода;
* проверку хардкода.

Также были выполнены проверки frontend:

```
cd frontend
npm run build
npm run lint
```

Проверка включает:

* сборку TypeScript;
* production-сборку Vite;
* проверку ESLint.

Дополнительно выполнялся аудит зависимостей:

```
cd backend
npm audit

cd ../frontend
npm audit
```
